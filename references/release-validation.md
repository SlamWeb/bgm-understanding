## 由真实样本发现的修正

APT. 的结构模型节拍从约5.9秒才开始；独立节拍模型从约0.3秒开始且速度一致。最终选择更完整的专门节拍网格，保留74拍，避免静默丢掉开头14拍。另一个样本存在倍速/密集拍点分歧，因此没有把“总优先专门模型”写成通用规则；每次保留同一模型的拍与小节网格，不拼接相位不同的结果。BPM用跨多个拍的间隔减轻20毫秒帧量化误差。

新增音频来自Apple公开试听；3首作品属于 [Spotify 2025年度全球热门歌曲](https://newsroom.spotify.com/2025-12-03/wrapped-top-artists-songs-albums-podcasts-audiobooks/)，不代表2026年实时抖音榜。只分析约30秒试听，试听在整曲中的偏移未知。测试音频及原始测量不随仓库分发。

示例JSON由APT.实测主输出生成，只调整文件名和本机证据路径。未附音频与详细证据，故示例用于说明接口，不能单独执行原音源完整性校验。

现有Windows CPU环境的模型身份、源码版本和依赖检查通过。安装器的计划/保护逻辑经过测试，完整干净机器安装与Linux模型推理尚未验证。段落名称、乐器、情绪和“值得切”的时间仍是候选；没有声称准确找到所有副歌、鼓或琴键。

## 独立 Agent 实跑

另一个 Agent 按skill单入口分析Lightning，使用隔离的分析缓存重新运行分轨和八fold结构推理，最终 receipt 的 `cache_hit=false`。CPU2线程，总耗时182.69秒，最大阶段进程树RSS约995MB。默认缓存命中试跑及一次隔离夹具配置失败另存，未冒充这次fresh结果。

最终主JSON为6406字节/62行：60拍、15个小节首拍、125个起音、29个走势窗口，216项机械校验通过。Agent仅凭主JSON制作了25图剪辑提案：开头问题停留，随后每小节切换，中段每两拍，末段每拍，结尾停住。所有内部切点来自主文件拍点数组；这验证了接口能支撑具体方案，没有验证渲染后的主观观感。

该Agent明确指出：变化点两侧都标为chorus，能量约0.83→0.87，不能宣称发现安静intro或强爆点。13.27秒只是结构变化候选，开头铺垫属于创作安排。模型时轴和音乐语义仍未经人工逐点听证。
